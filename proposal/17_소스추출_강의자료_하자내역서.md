## A. 「(아파트) 하자소송의 쟁점」 — 법무법인 제이엘 하혜용 변호사, 2026-07-02 (pptx 20장)

### 절차·기간
- 소송 절차 11단계: 소송결의 → 소장 접수 → 피고 답변서 → 원고 감정신청 → 감정인 지정·감정료 납부 → 감정기일 → 감정인 현장조사 → 감정보고서 → (감정보완신청) → 변론기일 2~3회 → 1심 판결. **감정 절차가 소송의 핵심** — 감정 결과에 따라 청구취지변경.
- 소요기간: **통상 1심 1년 6개월 내, 항소심 8개월 내.** 하자조사 → 소제기(≈8개월) → 감정서 도착(≈15개월) → 판결(≈18개월). 보완감정·준비서면 공방 단지에 따라 6~10개월.

### 청구원인·소가
- 집합건물법 제9조 담보책임(민법 667·668 준용). 시공자 책임은 분양자 회생·파산·무자력 시(제9조 제3항).
- 존속기간 제9조의2: 주요구조부·지반 10년, 그 외 5년 범위 내(시행령). 기산점 전유=인도일, 공용=사용검사일.
- **소가 산정 실무: 최초 소장은 세대당 200만원 내외** (500세대 → 약 10억). 감정서 후 청구취지변경으로 확정.
- 미시공·변경시공 하자는 기산일 이전 발생 하자로 **5년** 적용.

### 당사자
- 원고: 입대의(채권양도 받아 수행). 보증금은 입대의 고유 권한으로 청구.
- **미양도 세대 비율만큼 패소** → 100%에 근접하게. 서명·날인은 등기부상 구분소유자, 공유자 전원. 신분증 사본 첨부.
- 소 제기 의결: 동대표 구성원 의결(입주자 X). 안건 3호 — 소 제기 / 변호사 선임·보수 / 채권양도 방식.
- 피고 확인 자료 5종: 분양계약서·건축물대장·등기사항전부증명서·신탁원부·하자보증서.
- 신탁사: 신탁 해지·종료 시 시행사가 인수 → 문언 엄격 해석. 소 제기 후 다툼 없는 사실로 정리, 비용 들더라도 안전하게.
- 보증사: 보증사고 = 하자 발생 + 청구 + 미보수. **'사용검사 후' 하자만 보증.** 보증금은 하자보수에만 사용 → 보증금만 청구 시 비용 회수 어려움. 채권양도 영향 없음.

### 하자의 내용
- 하자 정의: 계약·설계도면·관계법령 기준 미달 또는 사회통념상 안전성·기능·내구성 결여. **세 가지 중 하나만 해당해도 하자** (2026 건설감정실무).
- **사용검사 전 하자 50~70%** (미시공·변경시공·오시공·설계하자) — 시행사·시공사 책임, **보증대상 아님**.
- 사용검사 후 하자 30~50% — 시행사·시공사·보증사 부진정연대, 보증대상.
- 허용 수치(재판에서 다투는 것): **콘크리트 균열 0.3mm 이상 하자 · 타일 뒷채움률 80% 미만 하자 · 옥상 우레탄 방수 두께 3mm(기준 두께 미달 시 하자)**.
- 하자 판정 기준 순서(대법원 판례 = 준공도면 기준): **1 준공도면 → 2 특기시방서 → 3 표준시방서 → 4 준공내역서.**
- 보수방법: 중요 하자 = 철거 후 재시공 / 중요하지 않은 하자 = 공사비 차액(재료비 vs 재료비+노무비 다툼).
- 보수비 산출 시점: 소 제기 시점으로 사실상 통일.
- 감정신청 항목 = 진단회사 항목 + 입주민 문제제기 + 기술팀 추가 진단.
- 특수 하자(성능검사 필요, 별도 판단): 방화문·HFIX·스프링클러·투수블럭·KS인증·단열성능·정착철근·방근시트. 드론조사: 500세대 이상·고층.

### 손해배상·기간·책임제한
- 배상 범위: 보수 가능 → 보수비 / 보수 불가·비중요 과다비용 → 공사비 차액(判). 예: 400만원 자재 대신 200만원 → 차액 200만원 + 추가 보수비.
- 지연손해금: 민법 387조, 이행청구 시부터. 하자관리계약이면 2~3년차 채권양도(60~80%) 후 미리 이행청구 → **최초 이행청구 시점**부터 이자.
- 소멸시효 10년, 제척기간 10년(보증금 청구 미적용). 보증금 소멸시효 보증사고 후 2~5년(보증사별).
- **책임제한: 3년차 소 제기 시 총액 20~30% 삭감, 1년 경과 시 5% 수준.** 사용검사 전 하자에도 적용.
