# 파주 운정 휴아림 — 분양전환 법률자문 & 단체등기 제안 (HTML 모션 버전)

원본: `0. 파주 휴아림 약식 단체등기제안서.pptx` (구글드라이브)

## 원본 PPT 사진 넣기 — 업로드 불필요

덱을 열고 **원본 pptx 파일을 화면에 그냥 끌어다 놓으십시오.**
pptx 는 내부적으로 압축파일이라, 덱이 직접 열어 안에 든 사진을 전부 꺼냅니다.

1. 덱을 브라우저로 엽니다
2. **원본 pptx 를 화면 위로 끌어다 놓습니다** (또는 `I` → `PPT 파일에서 사진 꺼내기`)
3. 꺼낸 사진이 갤러리에 뜹니다 (큰 사진부터, 로고·아이콘은 자동 제외)
4. **사진을 누르고 → 넣을 자리를 누릅니다**
5. 넣은 사진은 이 컴퓨터에 저장되어 다음에 열어도 그대로 있습니다

사진을 누르면 **전체화면으로 확대**됩니다. 휠로 확대, 끌어서 이동 — 계약서·공고문을 설명할 때 쓰십시오.

## 어떤 파일을 쓰면 되나

**그냥 발표만 하실 거면 → `파주휴아림_분양전환제안서.html` 하나만 받아서 더블클릭하십시오.**
폰트까지 안에 들어있어 인터넷 없이도, 다른 PC에서도 똑같이 보입니다.

원본 사진(설명회·게시판 공지)까지 넣으시려면 폴더 전체를 받아 `index.html` 을 쓰셔야 합니다.

## 모션 설계
PowerPoint식 "나타내기"가 아니라 웹 앱 수준의 모션을 씁니다.
- **스프링 물리 이징** — 감쇠 곡선(`linear()`)으로 자연스러운 관성과 미세 오버슛
- **키네틱 타이포그래피** — 슬라이드 제목이 단어 단위로 3D 회전하며 세워짐
- **깊이 전환** — 장 전환 시 스케일 푸시 + 광택 스윕
- **앰비언트 배경** — 브랜드 색 그러데이션 오브가 20~30초 주기로 천천히 흐름 + 미세 그레인
- **단계 포커스** — 지난 단계는 흐려지고 현재 단계만 선명 (`G` 로 끄기)
- **데이터 모션** — 막대 성장 + 광택 스윕, 숫자 카운트업 + 탄성, SVG 선 드로잉
- 전 구간 `transform`/`opacity` 위주로 처리해 전체화면 블러를 배제 (드롭 프레임 0~6/75)

## 발표자 단축키
| 키 | 기능 |
|---|---|
| `→` `Space` | 다음 단계 / 다음 장 |
| `←` | 이전 단계 / 이전 장 |
| `Enter` | 현재 장의 모든 단계 한 번에 펼치기 |
| `L` | 레이저 포인터 (한 번 더 누르면 크게) |
| `S` | 스포트라이트 |
| `D` / `X` | 펜 필기 / 지우기 (`1` `2` `3` 색상) |
| `B` | 블랙아웃 |
| `T` / `R` | 경과 타이머 / 초기화 |
| `G` | 지난 단계 흐리게 (집중 모드) 켜고 끄기 |
| `O` / `F` / `P` / `H` | 목차 / 전체화면 / 인쇄(PDF) / 도움말 |

무선 프리젠터는 대부분 `PageUp`/`PageDown` 을 보내므로 별도 설정 없이 동작합니다.
