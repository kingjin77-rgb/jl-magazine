# 단지정보 입력표

**새 단지에 제안할 때 채우는 유일한 문서.** 여기만 채우면 가변 6장(표지·현황·타임라인·집계·이력·사양대조)이 만들어진다. 나머지 25장은 손대지 않는다.

---

## 필수 6개 — 이것만 있으면 제안서가 나온다

| # | 항목 | 예시 | 어디에 쓰이나 |
|---|---|---|---|
| 1 | **단지명** | 이스트힐아파트 | 표지, 전 슬라이드 헤더 |
| 2 | **총 세대수 / 동수** | 1,444세대 / 14개동 | 표지, 현황표, 감정료 규모 산정 |
| 3 | **사용검사(사용승인)일** | 2016-11-01 | **담보책임기간 타임라인 전체** |
| 4 | **입주개시일** | 2017-01-15 | 전유부분 기산점 |
| 5 | **시행사** | 한국토지주택공사(LH) | 청구 상대방 |
| 6 | **시공사** | 임광토건(주) | 청구 상대방 |

> **3번이 없으면 제안서의 핵심 1장(담보책임기간 타임라인)을 만들 수 없다.** 관리사무소에 사용검사필증을 요청하거나 K-apt 단지정보에서 확인한다.

## 선택 — 있으면 해당 슬라이드가 살아난다

| 항목 | 없으면 |
|---|---|
| 소재지(법정동·도로명) | 표지 부제에서 생략 |
| 관리방식 / 난방 / 복도유형 / 분양형태 | 현황표에서 해당 행 삭제 |
| 하자보수보증서 (기관·금액·기간·번호) | S12 청구 3축에서 보증기관 축이 빠짐 |
| 하자 접수 집계 (유형별·동별 건수) | **S6 삭제** |
| 하자보수 요청 이력 (연도별 공문·회신) | **S7 삭제** |
| 입주자모집공고문 / 분양 카탈로그 | **S8 삭제** |
| 단지 전경 사진 | 표지가 추상 그래픽판으로 자동 전환 |
| 하자 현장 사진 | 사례 사진(계층 2)으로 대체 |

## 입력 방법

`template/data/` 에 JSON 파일을 하나 만든다. `_example_이스트힐.json`을 복사해 값만 바꾸면 된다.

```bash
cp template/data/_example_이스트힐.json template/data/단지명.json
# 값 수정 후
python3 tools/timeline.py template/data/단지명.json
```

날짜는 반드시 `YYYY-MM-DD` 형식. 모르는 값은 `null`로 둔다 — 빈 문자열이 아니라 `null`이어야 해당 슬라이드가 자동으로 빠진다.

## 타임라인 계산 확인

입력 후 위 명령을 실행하면 공종별 만료일과 상태가 나온다. **제안서에 넣기 전에 이 출력을 눈으로 확인한다.**

```
구분                              만료일         잔여    상태
주요구조부 · 지반공사               2026-11-01     2개월   임박
구조상·안전상                      2021-11-01   58개월경과  도과
기능상·미관상                      2019-11-01   82개월경과  도과
마감공사                          2018-11-01   94개월경과  도과
```

- **도과** `#C0392B` — 이미 지난 구간. 숨기지 않고 그대로 표시한다
- **임박** `#E67E22` — 12개월 내 만료. 제안의 근거가 되는 구간
- **여유** `#0F2548` — 아직 시간이 있는 구간

전 구간이 도과로 나오면 그 단지는 하자소송 제안 대상이 아닐 수 있다. 담당 변호사에게 먼저 확인한다.

## 발주처 상황 — 제안 톤 조정용 (선택)

파일이 아니라 메모로 적어 두면 S30(예상 질의응답)에 반영된다.

- 입대의 구성 (회장·감사·동대표 수, 임기 만료일)
- 제안서 제출 기한 / 발표 일자 / 발표 시간(분) → **발표 15분 이하면 요약본 10장으로 간다**
- 경쟁 법인 수, 입찰 여부
- 입대의가 걱정하는 지점 (비용? 기간? 동의서 징구? 과거 실패 경험?)
