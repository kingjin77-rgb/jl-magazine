## 자료 전달 경로

세션이 클라우드에서 실행되므로 사용자 PC 로컬 폴더를 직접 읽을 수 없다. **구글드라이브를 브리지로 사용**한다.

```
하자소송_제안서_자료/          (구글드라이브)
  0_먼저읽기_자료요청서
  1_입력양식_E_F_G
  A_법인브랜드자산/
  B_인적구성/
  C_수행실적/
  D_대상단지자료/  D1_단지기본_사용검사 · D2_하자보수이력_공문 · D3_하자사진 · D4_분양공고문_카탈로그 · D5_단지전경_조감도
  E_발주처상황/
  F_수임조건/
  G_산출물사양/
  H_참고자료/      H1_과거JL제안서 · H2_타법인제안서 · 2_참고자료_안내
```

## 다음 단계

1. 자료 입력 (구글드라이브)
2. `01_제안서_구성안.md`의 `{{슬롯}}`을 실제 값으로 치환
3. 레이아웃 방향 확정 (`05_디자인사양.md` 3안 중 선택)
4. Claude Design 캔버스 제작 → PPTX/PDF 산출

## 원칙 (bunyang-analysis 표준 승계)

- 금지 표현: 시나리오, 골든타임, 구호형 제목, 영어 남용, "약속드립니다", "최고", "유일"
- 표준 표현: 수행 실적, 이행 계획, 검토의견, 대응 체계
- 슬라이드 제목은 결론 문장형
- 권리로 단정 가능한 것과 요청·협의 사항을 구분 표기
- 인용은 원문 그대로, 추정치는 계산식 병기, 미확인은 `[미확인]`
- 회수 금액 단정 예측 금지, 승소 보장 금지
