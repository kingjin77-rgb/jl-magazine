## 1. 공통 기준 — 3안 공통 적용

### 팔레트 (bunyang-analysis 표준 승계)

| 역할 | 색상 | 용도 |
|---|---|---|
| NAVY | `#0F2548` | 주색. 헤더, 제목, 브랜드바, 본문 강조 |
| BLUE | `#3E6CB5` | 보조. 도표 계열, 링크, 부제, 차트 기본 시리즈 |
| RED | `#C0392B` | 경고 전용. 기간 도과, 미이행, 위험 표시 |
| INK | `#1A1A1A` | 본문 텍스트 |
| GRAY | `#6B7280` | 캡션, 주석, 출처 |
| LINE | `#E5E7EB` | 구분선, 표 괘선 |
| BG | `#FFFFFF` | 기본 배경 |
| BG-ALT | `#F5F7FA` | 카드·표 헤더 배경 |

**RED는 경고에만 쓴다.** 장식이나 강조 일반에 쓰면 정작 위험 표시가 묻힌다.

### 아트보드

| 용도 | 규격 | 비고 |
|---|---|---|
| 발표용 16:9 | 1332 × 750 | 기준 아트보드. 캡처 시 `--force-device-scale-factor=2` → 2664 × 1500 |
| A4 인쇄 책자 | 210 × 297mm (2480 × 3508 @300dpi) | 16:9 2장 = A4 1장 재조판. 여백 상하 20mm / 좌우 18mm |

G-1(출력 형태) 회신 전까지는 **16:9를 기준으로 제작**하고, 책자 요청 시 재조판한다.

### 서체

- 기본: **Pretendard** (SIL OFL, 상업 이용 가능)
- 제목 700 / 부제 600 / 본문 400 / 캡션 400
- A-5(보유 서체 라이선스) 회신 시 교체

| 요소 | 크기(1332px 기준) | 자간 |
|---|---|---|
| 슬라이드 제목 | 40px / 700 | -0.02em |
| 부제 | 22px / 600 | -0.01em |
| 본문 | 19px / 400 | 0 |
| 표 내부 | 17px / 400 | 0 |
| 캡션·출처 | 14px / 400 | 0 |

### 고정 요소

- **하단 브랜드바**: 전 슬라이드 고정. 좌측 법인 로고, 우측 페이지 번호. 높이 44px, NAVY 배경 또는 NAVY 상단 1px 라인.
- **AI 여백 금지**: 콘텐츠로 화면을 채운다. 가운데 텍스트 몇 줄에 사방 여백만 남는 구성을 만들지 않는다.
- **인용 처리**: 공고문·공문 인용은 **원문 그대로** + 형광 하이라이트(`#FFF3A3`). 요약하거나 다듬지 않는다.
- **모식도 표기**: 실측이 아닌 개념도에는 "모식도" 캡션을 단다.
- **추정치 표기**: 계산식 병기. 미확인 항목은 `[미확인]`.

## 2. 레이아웃 방향 3안 — 선택 필요

같은 26장 내용을 세 가지 방식으로 담을 수 있다. **하나를 고르시면 그 방향으로 캔버스를 제작**합니다.

### A안 — 정공법 (검토보고서 승계)

기존 JL 분양공고문 검토보고서의 형식을 그대로 이어받는 안.

- 상단 NAVY 제목 바(높이 96px) + 흰 본문 영역
- 제목은 좌측 정렬 결론 문장형 ("담보책임기간이 2027년 3월 도과합니다")
- 본문은 2단 또는 표 중심. 정보 밀도 높음
- 사진은 본문 안에 정사각/4:3 썸네일로 배치
- 이미지 의존도 **낮음** — 자료가 부족해도 완성됨

적합: 발표 시간이 짧고 심사위원이 내용을 빠르게 훑어야 할 때. 자료가 아직 다 안 모였을 때.
위험: 시각적으로 무난해서 경쟁 제안서 사이에서 눈에 덜 띈다.

### B안 — 다큐멘터리 (사진 전면)

하자 현장 사진을 전면에 세우는 안.

- 표지·PART 간지는 **풀블리드 사진** + NAVY 반투명 오버레이 + 흰 텍스트
- 본문은 흰 배경으로 전환해 가독성 확보
- PART 1(왜 지금인가) 구간에서 하자 사진을 크게 씀 — 좌 사진 / 우 설명 분할
- 이미지 의존도 **높음** — D3(하자사진) 30장 이상, D5(단지 전경) 고해상 필수

적합: 입주민 정서에 호소해야 할 때. 하자가 시각적으로 명확할 때. 총회 발표용.
위험: 사진 품질이 낮으면 역효과. 카톡 압축본으로는 성립하지 않음.

### C안 — 데이터 리포트 (숫자 중심)

수치와 도표로 밀고 나가는 안.

- 카드형 그리드. 숫자 타일(KPI) + 차트 + 표
- 여백을 절제하고 정보를 조밀하게 배치
- 사진은 작은 근거 자료로만 등장
- 인포그래픽 비중 최대 — 그래픽 5종이 각각 1장씩 온전히 차지
- 이미지 의존도 **중간** — 대신 D6(하자 접수대장) 수치 데이터가 반드시 필요

적합: A4 인쇄 책자로 배포할 때. 심사위원이 정량 근거를 중시할 때.
위험: 데이터가 부실하면 빈 껍데기가 된다.

### 권장

**A안을 기본으로 하되 PART 1 구간만 B안 방식으로 처리하는 혼합**을 권합니다. 전체 신뢰감은 정공법으로 가져가고, 승부처인 "왜 지금인가"에서만 사진을 크게 써서 밀도를 올리는 방식입니다. 자료 확보 상황에 관계없이 성립하고, 사진이 많이 들어오면 B 비중을 늘리면 됩니다.

## 4. 그래픽 5종 사양

### ① 담보책임기간 타임라인 (S5) — 최우선

제안서 전체에서 가장 중요한 1장. 이것만으로 "지금 해야 한다"가 설명되어야 한다.

- 가로 타임바. 좌측에 공종명(내력구조부·방수·창호·마감 등), 우측으로 기간 막대
- 기산점: `{{사용검사일}}` (D-2). 공용부분 기준
- 각 막대 끝에 만료일 표기, 계산식 병기 (`2019-03-15 + 5년 = 2024-03-15`)
- **오늘 날짜에 세로 기준선** — 이 선을 넘어간 막대가 도과분
- 색: 도과 `#C0392B` / 12개월 내 도과 `#E67E22` / 여유 `#0F2548`
- **도과분을 숨기지 않는다.** 정직하게 표시하고 남은 구간에 집중한다는 논리로 쓴다

### ② 채권양도 구조 도해 (S9)

- 상단: 구분소유자 다수(아이콘 그리드) → 화살표 "손해배상채권 양도" → 입주자대표회의 → 화살표 "소 제기" → 법원
- 하단에 동의율 게이지: 동의 세대수 / 전체 세대수 = 청구 규모
- "모식도" 캡션

### ③ 소송 절차 플로우 (S12)

- 8단계 가로 플로우: 사전조사 → 동의서 징구 → 소제기 → 감정 → 감정결과 협의 → 조정/판결 → 회수 → 보수공사 집행
- 각 단계 하단에 소요 기간 밴드
- 법인이 수행하는 구간과 입대의가 관여하는 구간을 색으로 구분

### ④ 하자 유형별·동별 집계 (S4)

- D-6 접수대장 기반. 상단 가로 막대(유형별 건수), 하단 히트맵(동 × 유형)
- 데이터 없으면 이 그래픽 삭제하고 S4는 표만

### ⑤ 비용 흐름 다이어그램 (S23)

- 착수 시점 → 감정 시점 → 회수 시점 3구간
- 각 구간에서 **누가 얼마를 내는가**를 화살표로. 법인 선납분과 입대의 부담분을 색 구분
- 패소 시 분기도 함께 표시 — 숨기지 않는다

## 5. 제작 순서

1. 마스터 슬라이드(헤더·브랜드바·타이포) 확정
