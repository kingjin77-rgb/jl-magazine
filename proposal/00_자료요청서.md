# 하자소송 제안서 — 자료 요청서

작성: 법무법인 JL / 제안서 제작 선작업 단계
목적: 디자인 착수 전, 제안서에 들어갈 **사실 데이터**를 확정한다. 여기서 확정되지 않은 항목은 디자인 단계에서 빈칸(placeholder)으로 남는다.

표기
- **[필수]** 없으면 제안서 제작 불가
- **[중요]** 없으면 해당 챕터를 통째로 삭제해야 함
- **[선택]** 있으면 설득력 상승, 없어도 진행 가능
