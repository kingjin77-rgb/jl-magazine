# 작업 폴더 구성 안내

대상: `C:\Users\corncake\Desktop\하자소송제안서작업`

## 왜 이 절차가 필요한가

제안서 제작 세션은 **클라우드 컨테이너**에서 실행됩니다. 사용자 PC의 `C:\` 드라이브와 물리적으로 분리되어 있어, 바탕화면 폴더에 자료를 넣어도 제가 읽을 수 없습니다. MCP를 추가해도 마찬가지입니다 — MCP 서버 역시 컨테이너 안에서 돌기 때문에 컨테이너가 못 보는 디스크는 MCP도 보지 못합니다.

그래서 **구글드라이브를 중간 다리로** 씁니다. 로컬 작업 폴더는 그대로 쓰시고, 정리가 끝난 자료만 드라이브로 올리시면 됩니다.

```
[내 PC 바탕화면]  →  [구글드라이브]  →  [제가 읽음]
  자료 정리            업로드            처리·제작
```

---

## 1단계 — 로컬 폴더 한 번에 만들기

아래 내용을 메모장에 붙여넣고 **`폴더생성.bat`** 으로 저장(파일 형식: 모든 파일, 인코딩: ANSI)한 뒤 더블클릭하세요. 바탕화면에 전체 트리가 한 번에 생깁니다.

```bat
@echo off
chcp 65001 > nul
set BASE=%USERPROFILE%\Desktop\하자소송제안서작업

mkdir "%BASE%\A_법인브랜드자산"
mkdir "%BASE%\B_인적구성"
mkdir "%BASE%\C_수행실적"
mkdir "%BASE%\D_대상단지자료\D1_단지기본_사용검사"
mkdir "%BASE%\D_대상단지자료\D2_하자보수이력_공문"
mkdir "%BASE%\D_대상단지자료\D3_하자사진"
mkdir "%BASE%\D_대상단지자료\D4_분양공고문_카탈로그"
mkdir "%BASE%\D_대상단지자료\D5_단지전경_조감도"
mkdir "%BASE%\E_발주처상황"
mkdir "%BASE%\F_수임조건"
mkdir "%BASE%\G_산출물사양"
mkdir "%BASE%\H_참고자료\H1_과거JL제안서"
mkdir "%BASE%\H_참고자료\H2_타법인제안서"

echo.
echo 폴더 생성 완료: %BASE%
echo.
explorer "%BASE%"
pause
```

> 배치 파일 실행이 꺼려지시면 탐색기에서 직접 만드셔도 됩니다. **폴더명은 드라이브와 정확히 같아야** 나중에 통째로 올릴 때 구조가 유지됩니다.

## 2단계 — 자료 채우기

각 폴더에 무엇을 넣는지는 `00_자료요청서.md` 또는 드라이브의 `0_먼저읽기_자료요청서` 를 보세요.

E(발주처 상황)·F(수임 조건)·G(산출물 사양)는 파일이 아니라 **글로 답하는 항목**입니다. 드라이브의 `1_입력양식_E_F_G` 문서에 바로 적어주시면 됩니다.

## 3단계 — 드라이브로 올리기

구글드라이브 `하자소송_제안서_자료/` 폴더가 이미 만들어져 있습니다. 두 가지 방법 중 편한 쪽을 쓰세요.

**방법 A — 드래그 업로드 (간단)**
1. 브라우저에서 드라이브의 `하자소송_제안서_자료` 폴더를 연다
2. 탐색기에서 로컬 하위 폴더(예: `D_대상단지자료`)를 통째로 드래그해 넣는다
3. 폴더 구조가 그대로 올라간다

**방법 B — Google Drive for desktop 동기화 (자료가 계속 늘어날 때)**
1. Google Drive for desktop 설치
2. 로컬 작업 폴더를 드라이브 폴더 안에 두거나, 해당 폴더를 동기화 대상으로 지정
3. 이후 로컬에 파일을 넣으면 자동 반영 — 매번 업로드할 필요 없음

## 4단계 — 알려주기

올리신 뒤 **"올렸다"** 한마디만 주시면 제가 읽고 처리합니다. 전부 다 채우실 필요 없습니다. 들어온 만큼 반영하고, 빠진 부분은 빈칸으로 표시해 다시 요청드립니다.

## 사진을 보내실 때 — 중요

- **카카오톡으로 전송받은 사진은 쓰지 마세요.** 전송 과정에서 자동 압축되어 해상도와 촬영일 정보가 손상됩니다. 인쇄 시 뭉개지고, 하자 사진은 증거 성격이라 원본성이 중요합니다.
- **카메라 원본 그대로** 주세요. 파일 용량이 커도 괜찮습니다.
- 촬영일이 파일 정보에 남아 있으면 그대로 두세요. 제안서에 캡션으로 씁니다.
- 하자 사진은 **위치를 알 수 있게** — 근접 촬영만 있으면 어디인지 알 수 없습니다. 가능하면 전경 1장 + 근접 1장 세트로.
- 로고는 벡터 파일(AI·SVG)이 있으면 그것을, 없으면 **가장 큰 해상도의 PNG**를 주세요. 홈페이지에서 우클릭 저장한 작은 이미지는 인쇄에 못 씁니다. (저해상만 있으면 제가 보정합니다)
