# 주요 하자 사례집 — PART 3의 원천

기본제안서 S14~S17의 내용. **"우리는 이런 하자를 찾아낸다"를 금액으로 증명하는 구간**이며, 이 제안서의 차별화 지점이다.

새 사례가 생기면 여기에 누적한다. 슬라이드는 이 문서를 참조해 갱신한다.

> 아래 금액은 기존 JL 제안서에서 추출한 값이다. **원본 재확인 후 수록**하며, 인터로 공동 수행 건은 JL 단독 제안서 사용 가부를 확인해야 한다.

**필요 사진**: 월패드 내부 개방 상태 / 통신단자함 내부 / 준공도면 해당 부분 — 각 1컷

## 사례 4 — 방화문 성능 미달

가장 기술적이고, 그래서 다른 법인이 잘 다루지 못하는 항목. **JL의 강점 구간.**

### 판단 기준

| 시험 | 규격 | 기준 |
|---|---|---|
| 내화 시험 | **KS F 2268-1** | 비차열 1시간 이상 + 차열 30분 이상 |
| 차연 성능 시험 | **KS F 2846** | 차압 25Pa일 때 공기누설량 0.9㎥/min·㎡ 미만 |

### 감정 절차 5단계

```
① 시료 선정        표본 위치·개소·철거 방법 확정, 원·피고 감정인 날인, 시험기관 선정 협의
② 방화문 철거      철거 후 신규 방화문을 해당 세대에 설치
③ 성능 시험        시료 운반·입고 → KS F 2268-1, KS F 2846 시험 입회
④ 결과 접수        시험기관 성적서 접수 및 확인
⑤ 감정서 작성      감정사항 작성, 감정금액 산출, 결과 보고
```

**인정 사례**: 제일풍경채센트럴 — 방화문 승소 판결 별도 확보 `[금액 원본 확인 필요]`

**필요 사진**: 방화문 철거 장면 / 시험기관 시험 장면 / 성적서 — 각 1컷

## 사진 사용 규칙 — 반드시 지킨다

1. **단지 식별정보 마스킹 필수**
   타 의뢰인의 하자 정보를 다른 단지 제안서에 그대로 노출하면 비밀유지 문제가 된다.
   `103동 1502호 거실` → `○○아파트 세대 거실`
2. **AI 생성·스톡 사진 사용 금지**
   하자 사진은 증거 성격이다. 실제 수행 단지의 실물만 쓴다.
3. **캡션 필수** — 하자 내용 + 촬영일. 단지명은 마스킹, 촬영일은 유지
4. **처리는 크롭·밝기 보정까지만** — 하자를 과장하는 방향의 보정 금지

## 사진 확보 현황

**사진 의존도를 낮춘 재설계.** 상세는 `12_하자사진_조달방안.md`.

| 사례 | 필요 사진 | 도해로 대체 | 현재 |
|---|---|---|---|
| 1 월패드 | **2장** (단자함 개방, 월패드 내부) | 결선도 모식도 병기 | 미확보 |
| 2 타일 | **1장** | 단면 모식도 + 뒤채움률 % | 미확보 |
| 3 방수 | **1~2장** (계측기 눈금 보이는 것) ★ | 단면 모식도 + 기준/실측 대비 | 미확보 |
| 4 방화문 | **0~1장** | KS 시험 절차 도해 + 성적서 수치 | 미확보 |
| | **합계 4~6장** | | |

방수 4종 중 3종은 **사진보다 도해가 더 설득력 있다**. 방수 두께 `3mm vs 1.82mm` 차이는 사진에 안 보이고 단면도에는 보인다.

**최우선 출처는 감정서다.** 드라이브에 `6. 감정서.pdf`가 이미 있다 — 원·피고 감정인 공동조사 사진과 실측 장면이 들어 있고, JL이 수행한 사건 자료라 "우리가 한 일"이라는 주장이 사실이다.

> **웹에서 가져오지 않는다.** 저작권 침해이자, PART 3이 "우리가 찾아낸 하자"를 증명하는 구간이므로 허위표시가 된다. 역검색 한 번이면 드러나고 경쟁 입찰에서 지적당하면 수임이 그 자리에서 끝난다.
