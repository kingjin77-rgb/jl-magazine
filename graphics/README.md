# 그래픽

제안서에 들어가는 도해·차트. **SVG로 직접 작성하고 PNG로 렌더**한다.

## 왜 SVG인가

- 브랜드 팔레트를 정확히 맞출 수 있다 (`11_브랜드_스타일가이드.md`)
- **치수가 정확하다.** 생성 이미지는 `3.0mm vs 1.82mm` 같은 수치를 못 맞춘다
- 수정이 자유롭고 버전 관리가 된다
- 라이선스 문제가 없다

## 렌더

```bash
python3 -c "
import cairosvg
cairosvg.svg2png(url='graphics/<파일>.svg', write_to='graphics/<파일>.png',
                 output_width=2400, output_height=1200)
"
```

한글 렌더에는 폰트 설치가 필요하다 (컨테이너 재생성 시 반복).

```bash
cp assets/fonts/*.ttf /usr/share/fonts/truetype/jl/ && fc-cache -f
```

## 규칙

- **수치는 실제 사례에서 가져오고 계산식을 도해 안에 병기한다.** 검산 가능해야 한다
- 개념도에는 **"모식도"** 캡션 + 과장 표시 여부를 명시
- 경고색(`#C0392B`, `#E67E22`)은 도과·부족 표시에만. 장식으로 쓰지 않는다
- 사례를 바꿀 때는 **제목·층 구성·수치가 서로 맞는지** 확인한다
  (예: `3.0mm vs 1.82mm`는 옥탑 노출우레탄 사례이지 욕실·발코니 방수가 아니다)
