# 내용 누락 검증

원본 PPT 전문(`original-text.txt`)과 `index.html`에서 추출한 텍스트를 기계적으로 대조한 결과입니다.

## 결과 (2026-08-19 기준)

| 검사 | 결과 |
|---|---|
| 원본 내용 줄 508개 대조 | **미반영 0줄** (완전 반영 411 · 부분 97) |
| 핵심 수치·고유명사 183개 개별 확인 | **누락 0개** |
| 분양전환등기 실적 51개 계약 건 | **단지명·세대수 전건 반영** |

"부분 반영" 97줄은 전부 실적표 행입니다. 원본은 한 줄에 `2024년 10월 미사강변 브라운스톤(리츠6호) 등기위수임계약 871세대`
로 붙어 있고, 제 덱은 `2024.10 / 미사강변 브라운스톤 / 리츠 6호 / 871` 로 표 칸을 나눠 담아
줄 단위 문자열 일치에서 걸리지 않은 것입니다. 단지명·세대수 개별 확인에서는 51건 전부 확인됐습니다.

## 재현 방법

```bash
# 1) 덱에서 텍스트 추출 (숨은 슬라이드까지 포함하려면 textContent 사용)
node -e "const{chromium}=require('playwright');(async()=>{const b=await chromium.launch();
const p=await b.newPage();await p.goto('file://'+process.cwd()+'/../index.html');
await p.waitForTimeout(1500);
require('fs').writeFileSync('mine-text.txt',
  await p.evaluate(()=>[...document.querySelectorAll('.slide')].map(s=>s.textContent).join('\n')));
await b.close();})()"

# 2) 대조 (정규화 후 줄 단위 + 어절 단위 포함률)
python3 diff.py
```
