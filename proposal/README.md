# 법무법인 제이엘 하자소송 기본제안서 — 작업공간

**재사용 마스터 템플릿.** 고정 25장 + 가변 6장. 단지 정보만 갈아끼워 매번 새 제안서를 낸다.

- 제안 주체: **법무법인 제이엘 단독**
- 전체본 31장 + 요약본 10장

## 새 단지에 제안할 때 — 이것만 하면 된다

```bash
cp template/data/_example_이스트힐.json template/data/단지명.json
# 필수 6개 채우기: 단지명 · 세대수 · 동수 · 사용검사일 · 입주개시일 · 시행사/시공사
python3 tools/timeline.py template/data/단지명.json
```

담보책임기간 만료일이 자동 계산된다. 상세는 `07_단지정보_입력표.md`.

## 자료 전달 경로

세션이 클라우드에서 실행되므로 사용자 PC 로컬 폴더를 직접 읽을 수 없다. **구글드라이브를 브리지로 사용**한다.

```
하자소송_제안서_자료/          (구글드라이브)
  0_먼저읽기_자료요청서
  1_입력양식_E_F_G
  A_법인브랜드자산/
  B_인적구성/
  C_수행실적/
  D_대상단지자료/  D1_단지기본_사용검사 · D2_하자보수이력_공문 · D3_하자사진 · D4_분양공고문_카탈로그 · D5_단지전경_조감도
  E_발주처상황/
  F_수임조건/
  G_산출물사양/
  H_참고자료/      H1_과거JL제안서 · H2_타법인제안서 · 2_참고자료_안내
```
