# 필요 이미지 리스트 — 60장 기준

슬롯 치수는 **렌더된 실제 크기를 측정한 값**이다. 이 비율에서 벗어나면 여백이 생기거나 잘린다.
2배 해상도로 주면 인쇄·확대에서도 깨지지 않는다 (예: 666×360 슬롯 → 1332×720 이상).

---

## 성격 구분 — 이걸 먼저 본다

| 구분 | 뜻 | 생성·스톡 |
|---|---|---|
| **증거** | "우리가 이런 하자를 찾아낸다"를 증명하는 자료 | **금지.** 역검색 한 번에 드러나고, 경쟁 입찰에서 지적당하면 수임이 그 자리에서 끝난다 |
| **장식** | 지면을 채우는 분위기용 | 실사 느낌이면 생성·무료 스톡 가능 |

증거 사진은 **감정서·하자조사보고서에서 발췌한 실물**만 쓴다.
타 단지 사진은 **동호수·단지명을 가린 뒤** 쓰고, 촬영일은 유지한다. **업스케일 금지**(없던 디테일이 생성된다).

## 생성 이미지로 만들 때 공통 조건

장식(01·10·11)만 해당한다. 증거 항목에는 쓰지 않는다.

```
photorealistic, no text, no logos, no people, no watermark, 2K 이상
```

- **글자가 들어가면 한글이 깨져서 못 쓴다.** `no text`를 반드시 넣는다
- 워터마크가 박히면 사용 불가

## 전달 방법 — 제가 직접 못 받아옵니다

이 작업 세션은 클라우드 컨테이너에서 돈다. 사용자 PC(`C:\Users\...`)를 읽을 수 없고,
이미지 사이트도 이 환경의 네트워크 정책에 막혀 있다. **2026-08 측정:**

```
github.com  400(도달)   pypi.org  200(도달)
unsplash · pixabay · freepik · wikimedia   000 (전부 차단)
```

세 가지 길이 있고 전부 사용자 쪽 조치다.

1. **로컬 창에서 작업** — 레포를 PC에 클론해 그 폴더를 Claude Code로 열면 하자사진을 바로 읽는다.
   **내부자료가 GitHub에 올라가지 않으므로 이 방법이 가장 안전하다**
2. **claude.ai/code에서 이 환경의 네트워크 정책 완화** — 그러면 제가 직접 받아온다
3. **대화창에 파일 첨부** — 첨부 파일은 `/mnt/attach/`로 들어온다.
   본문에 붙여넣으면 파일로 안 들어오고, 끌어다 놓아야 한다. 여러 장 한 번에 가능

받은 파일은 아래에 넣는다.

| 자료 | 위치 |
|---|---|
| 하자 사진 (증거) | `assets/defect-photos/` — **내부자료이므로 커밋하지 않는다** |
| 표지·간지 배경 (장식) | `template/design/` — 내부자료가 아니므로 커밋 가능 |
| 변호사 사진 | `assets/lawyers/` |
| 감정서 PDF | 첨부만 하면 원본 해상도로 사진면을 추출한다 |
