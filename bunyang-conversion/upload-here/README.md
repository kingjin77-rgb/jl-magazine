위 주소가 안 열리면 아래 순서로 하십시오.

2. 파일 목록 위 **브랜치 선택 단추**(기본값 `main`)를 눌러 **`claude/apartment-conversion-html-9iquhg`** 선택
3. `bunyang-conversion` 폴더 → `upload-here` 폴더 클릭
4. 오른쪽 위 **`Add file`** → **`Upload files`**
5. 파일을 창 안으로 끌어다 놓기
6. 화면 아래 초록색 **`Commit changes`** 클릭

## 올려주실 것

### 1순위 — 제안서 사진 (설명회·게시판 공지)
1. `0. 파주 휴아림 약식 단체등기제안서.pptx` **복사본**을 만듭니다
2. 복사본의 확장자를 **`.pptx` → `.zip`** 으로 바꿉니다
3. 압축을 풉니다 → **`ppt\media`** 폴더에 제안서의 모든 사진·스캔이 원본 화질 그대로 들어 있습니다
4. 그 폴더 안 파일을 **전부 선택해서** 위 5번 자리에 끌어다 놓습니다

### 2순위 — 변호사 사진
`법무법인제이엘변호사소개.pdf` 또는 변호사 개인 사진 파일

### 3순위 — 원본 PPT 통째로 (선택)
깃허브 웹 업로드는 파일당 25MB까지입니다. 원본이 36MB라 그대로는 안 올라갑니다.
파워포인트에서 **`파일 > 정보 > 미디어 크기 및 성능 > 미디어 압축`** 을 먼저 실행하면 보통 25MB 아래로 줄어듭니다.
이걸 올려주시면 **원본 60장을 이미지로 렌더링해 제 36장과 1:1 대조표**를 만들어 드릴 수 있습니다.
