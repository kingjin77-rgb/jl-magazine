# 슬라이드 규격서 — 좌표·크기·강조 규칙

**101장에 강제하는 단일 기준.** 감으로 배치하지 않는다. 이 표의 숫자만 쓴다.

출처: 사용자가 제시한 단체등기 제안서 스타일 지침(`제안서_스타일_전달명령어.md`)의
좌표 체계와 강조 규칙을 하자소송 제안서 캔버스로 환산한 것. **색·서체는 우리 것을 유지한다.**

## 환산 기준

단체등기 지침은 13.33 × 7.5 in 기준이고 우리 아트보드는 1332 × 750 px다.
**1 in = 100 px** 로 떨어진다. 지침의 인치값에 100을 곱하면 그대로 우리 좌표다.

pt → px 는 `× 4/3` (96dpi 기준).

## 1. 페이지 골격

| 항목 | 값 (px) | 비고 |
|---|---|---|
| 아트보드 | 1332 × 750 | 16:9 |
| 좌우 마진 | **56** | 지침은 75. 우리 덱은 56으로 이미 통일돼 있어 56을 유지한다 |
| 본문 폭 | **1220** | 1332 − 56×2 |
| 헤더 밴드 | 0 ~ 160 | 네이비 그러데이션 `150deg #385783 → #2A3B4F` |
| 헤더 하단 금선 | 160 ~ 164 | `--gold #B08D4F`, 4px |
| 러너 (문서명) | top 28 | 15px, 흰색 |
| 아이브로 (챕터 라벨) | left 56, top 70 | 17px 700, `#EBD9B4`, 앞에 32px 금색 선 |
| 제목 | left 56, top 96 | **35px 800**, 흰색, line-height 1.34 |
| 본문 시작 | **top 186** | 헤더 아래 22px 띄움 |
| 본문 끝 | **bottom 96** | 검증 밴드가 있는 장은 그 위까지 |
| 푸터 | bottom 0, 높이 36 | 상단 2px 네이비 선 |

**본문 시작 top은 186 하나로 통일한다.** 현재 160·186·188·152·150·190·196·172 가 섞여 있다.

## 2. 열 배치 (지침 그대로 · ×100 환산)

마진 56 기준으로 재계산한 값이다.

| 구성 | 좌표 (px) | 카드 폭 | 간격 |
|---|---|---|---|
| 2열 | 56 / 694 | 582 | 56 |
| 3열 | 56 / 475 / 894 | 380 | 39 |
| 4열 | 56 / 366 / 676 / 986 | 290 | 20 |
| 5열 | 56 / 306 / 556 / 806 / 1056 | 220 | 30 |

**5열을 넘기지 않는다.** 6칸 이상이 필요하면 2행으로 접는다.

## 3. 글자 크기 — 상자에 맞춰 키운다

지침의 핵심: **"본문 최소 9.5pt, 주력 11~13pt — 상자 크기에 맞춰 키운다.
상자에 비해 글이 작으면 안 된다 (인쇄 기준)"**

| 용도 | pt | **px** |
|---|---|---|
| 슬라이드 제목 | 23~26 | **31~35** |
| KPI 큰 숫자 | 36~44 | **48~59** |
| KPI 단위 | 14~16 | **19~21** |
| 카드 소제목 | 12~14 | **16~19** |
| 카드 본문 | 11~12.5 | **15~17** |
| 표 | 9.5~11 | **13~15** |
| 각주·출처 | 9.5~10 | **13** |

**13px 미만을 쓰지 않는다.** 인쇄하면 읽히지 않는다.

## 4. 색 — 회색 글씨 금지

| 용도 | 값 |
|---|---|
| 본문 검정 | `#111418` |
| 보조 본문 | `#44526E` (흰 배경 대비 8.0:1) |
| 강조 네이비 | `#223D5B` |
| 면·바 | `#385783` |
| 금색 (라벨·구분선) | `#B08D4F` / 어두운 곳 `#EBD9B4` |
| 경고 빨강 | `#C0392B` |
| 카드 배경 | `#E9EDF8` |
| 선 | `#C6CFE0` |

- **회색 글씨 금지.** 인쇄하면 안 보인다. 어두운 배경 위 밝은 글씨는 예외
- `#7F8CA6` 같은 중간 회색을 본문에 쓰지 않는다 → `#44526E`
- 어두운 카드 안 글씨는 반드시 흰색. 상속 색 방치 금지

## 5. 강조 규칙 — 내용으로 판단한다

지침의 판단 기준을 그대로 가져온다. **규칙을 일괄 적용하지 않는다.**

**강조하는 것**

- 심사위원이 채점표에 옮겨 적을 숫자 → 크게(48~59px), 네이비
- 우리가 하는 일 vs 입대의가 하는 일 → 색으로 구분
- 흐름의 현재 위치·결과 단계 → 마커 또는 마지막 카드
- 경고·전제 조건 → 네이비 배너

**강조하지 않는 것**

- 같은 급 항목 나열(변호사 4인, 절차 11단계, 하자 14종) — **첫 카드만 색 강조 금지**
- **체크 표시(✓) 금지** → 번호 배지 또는 굵은 점
- **붉은 박스 테두리 금지** (구식) → 네이비 세로바 6px + 텍스트.
  빨강은 마커·경고에만

## 6. 표

- 이름 왼쪽, 숫자 오른쪽
- 숫자 컬럼끼리 **간격 27px 이상**, 색을 달리해 붙어 보이지 않게
- 숫자는 `font-variant-numeric: tabular-nums`

## 7. 이미지

- 사진은 **카드를 꽉 채운다** (`object-fit:cover`).
  카드 왼쪽에 작은 사진 + 오른쪽 텍스트 + 빈 여백 패턴은 쓰지 않는다
- 나란한 사진은 비율 통일. 캡션은 사진 아래 가운데
- **같은 사진을 두 장에 쓰지 않는다.** 파일명이 달라도 내용이 같으면 중복이다
  (검사: `tools/spec_audit.py` 가 내용 해시로 잡는다)
- 타 단지 사진은 동호수·단지명 마스킹
- 하자 사진은 실사만. 표지·간지는 생성 이미지 가능 (`14_표지간지_이미지_프롬프트.md`)

## 8. 문장

- 결과를 약속하지 않고 행동만 약속: "반영됩니다" ✗ → "요구 공문을 발송하고 회신을 받습니다" ○
- 숫자로 쓴다: "충분한 인력" ✗ → "정직원 36명" ○
- AI 상투어 금지: 혁신적·차별화·최첨단·토탈 솔루션·시너지·패러다임·원스톱
- 승소 보장·회수 금액 단정 금지
- 실적은 **"하혜용 변호사 수행"** 단위 (`10_JL_수행실적.md` 귀속 원칙)
