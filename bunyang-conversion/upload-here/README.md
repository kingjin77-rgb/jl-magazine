# 여기에 올려주세요

이 폴더에 파일을 올리시면 제가 저장소에서 직접 받아 처리합니다.
제 쪽으로 따로 보내실 필요 없습니다.

## 올리는 방법 (깃허브 웹에서)

1. https://github.com/kingjin77-rgb/jl-magazine 접속
2. 좌측 상단 브랜치 선택기에서 **`claude/apartment-conversion-html-9iquhg`** 선택
3. `bunyang-conversion` → `upload-here` 폴더 진입
4. 우측 상단 **`Add file` → `Upload files`**
5. 파일을 끌어다 놓고 아래 **`Commit changes`** 클릭

## 무엇을 올리면 되나

**방법 A — 이미지만 (권장, 가장 빠름)**
1. `0. 파주 휴아림 약식 단체등기제안서.pptx` **복사본**을 만들고 확장자를 `.zip` 으로 변경
2. 압축 해제 → `ppt\media\` 폴더에 제안서의 모든 사진·스캔이 원본 화질 그대로 들어 있습니다
3. 그 폴더 안 파일을 **전부 선택해서** 위 4번 자리에 끌어다 놓기

**방법 B — PPT 파일 통째로**
- 깃허브 웹 업로드는 파일당 25MB까지입니다. 원본이 36MB라 그대로는 안 올라갑니다.
- 파워포인트에서 **`파일 > 정보 > 미디어 크기 및 성능 > 미디어 압축`** 을 먼저 실행하시면
  보통 25MB 아래로 줄어듭니다. 그 파일을 올려주시면 제가 압축을 풀어 이미지를 꺼내겠습니다.
- 이 경우 원본 장표를 이미지로 렌더링해 **원본 60장과 제 36장을 1:1로 대조**하는 것도 가능해집니다.
