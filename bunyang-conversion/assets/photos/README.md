# 원본 이미지 넣는 위치

원본 PPT(`0. 파주 휴아림 약식 단체등기제안서.pptx`)에서 이미지를 꺼내 이 폴더에 넣으면
슬라이드에 자동으로 표시됩니다. 파일이 없으면 "사진 삽입 위치" 안내 박스로 표시됩니다.

## 이미지 꺼내는 방법
1. pptx 파일의 **복사본**을 만들고 확장자를 `.zip` 으로 변경
2. 압축 해제 → `ppt/media/` 폴더에 모든 사진·스캔이 원본 화질로 들어 있습니다
3. 아래 이름으로 바꿔 이 폴더에 넣습니다 (jpg / png 모두 가능, 확장자는 .jpg 로 통일)
