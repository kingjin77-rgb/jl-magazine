## 3. 기존 제안서 구성 (5장 48면)

```
1. 하자처리 안내      단지 기본정보(K-apt) → 처리 일정 → 관련 법령 → 집합건물법 제9조·제9조의2
2. 하자조사, 소송      하자조사 절차(90일) → 도면검토 → 진단보고서 → 주요하자 5종 → 채권양도 →
                      세대 체크리스트 → 내용증명 → 시공사 보수제안 검토 → 상대방 재무제표 →
                      적정시기 → 판결사례 → 감정신청 → 소송절차 11단계
3. 사업제안 및 실적    수임 단지 목록 → JL 판결실적 → 소송지원 사례 → 최근 판결 실적표 → 단계별 지원계획
4. 법무법인 소개       대표변호사 인사 → 변호사 프로필 → 배상책임보험 → 전문분야 등록증 → 사무장 →
                      경쟁력 → 사무소 위치
5. 질문 답변
```

## 4. 기존 제안서의 강점 — 유지할 것

1. **주요 하자 5종을 실적 금액과 함께 제시** — 추상적 설명이 아니라 "이 하자는 다른 단지에서 얼마 받았다"로 연결. 가장 설득력 있는 구간.
2. **채권양도율을 공개** — 87~99%. 입대의의 최대 걱정거리에 실측치로 답한다.
3. **소송 절차 11단계에 각 단계 소요기간 명시** — 1심 2년6개월 종결 표방.
4. **소송 제반비용(감정료·인지대·송달료) 전액 법무법인 대납** — 입대의 부담 0. 가장 강한 조건.
5. **상대방 재무제표 첨부** — 시공사/시행사의 지급 능력을 미리 검증해 보여줌. 다른 법인에 없는 디테일.
6. **책임제한 판결을 숨기지 않고 실음** (죽림부영 55%) — 정직성이 신뢰를 만든다.
7. 자격·보험·전문분야 등록증을 원본 이미지로 제시.

## 5. 개선할 것

| 문제 | 개선 |

| OCR 품질로 볼 때 **원본 해상도·조판이 거친 상태**. 표가 깨지고 글자가 뭉개진 면이 많다 | 전면 재조판 |

| 실적 표가 숫자 나열. **세대당 금액의 의미가 안 보임** | 차트화. "우리 단지 규모면 대략 이 정도" 환산 제시 |

| 광고 규정 관련 **승소 표현이 다수** ("승소판결", "최상의 결과 도출") | 변협 규정 확인 후 표현 조정 |
