## 1. 공통 기준 — 3안 공통 적용

### 팔레트 — **JL 실제 브랜드** (지명원 추출 확정)

| 역할 | 값 | 용도 |
|---|---|---|
| PRIMARY | `#385783` | 대제목, 번호, 제목 마크, 섹션 구분선. **주색** |
| INK | `#223D5B` | 본문 짙은 텍스트, 카드 소제목 |
| DARK | `#2A3B4F` | 상단 러너, 페이지 번호 |
| MUTED | `#8289A3` | 영문 서브타이틀, 캡션 |
| CARD | `#E9EDF8` | 카드·배지 배경 |
| WATERMARK | `#C7CEE1` | 대형 워터마크 |
| LINE | `#DDE2EC` | 카드 테두리, 표 괘선 |
| BG | `#FFFFFF` | 배경 |

**경고 전용 추가색** — 브랜드에 없으므로 S5 타임라인 한 장에만 쓴다.

| ALERT | `#C0392B` | 담보책임기간 **도과** |
| WARN | `#E67E22` | **12개월 내 도과 임박** |

> 이전 팔레트(NAVY #0F2548 / BLUE #3E6CB5 / RED #C0392B)는 분양공고문 검토보고서 표준이었고 JL 브랜드가 아니었다. 상세는 `11_브랜드_스타일가이드.md`.

### 아트보드

| 용도 | 규격 | 비고 |
|---|---|---|
| 발표용 16:9 | 1332 × 750 | 기준 아트보드. 캡처 시 `--force-device-scale-factor=2` → 2664 × 1500 |
| A4 인쇄 책자 | 210 × 297mm (2480 × 3508 @300dpi) | 16:9 2장 = A4 1장 재조판. 여백 상하 20mm / 좌우 18mm |

G-1(출력 형태) 회신 전까지는 **16:9를 기준으로 제작**하고, 책자 요청 시 재조판한다.

### 서체 — 확정

- 기본: **210 옴니고딕** (010/020/030/040/050 5종 확보 — 드라이브 `fonts/`)
- 보조: **에코드림** — 파일 미확보, 수급 필요
- 제목 옴니고딕 050(굵게) / 부제 040 / 본문 030 / 캡션 020
- 폴백: Pretendard (SIL OFL) — 웹 산출물 및 폰트 미설치 환경용
- `[확인 필요]` 210 옴니고딕의 상업적 사용·임베딩 라이선스 조건
- **사용 금지**: 맑은고딕·굴림·Times New Roman 등 Windows 동봉 폰트 (배포 라이선스 문제)

| 요소 | 크기(1332px 기준) | 자간 |
|---|---|---|
| 슬라이드 제목 | 40px / 700 | -0.02em |
| 부제 | 22px / 600 | -0.01em |
| 본문 | 19px / 400 | 0 |
| 표 내부 | 17px / 400 | 0 |
| 캡션·출처 | 14px / 400 | 0 |

### 고정 요소 — 지명원 문법 승계

- **상단 러너**: 좌 `◆ 법무법인 제이엘 · 하자소송 제안서` (MUTED) / 우 `08 / 31` (DARK)
- **제목 마크**: 대제목 왼쪽에 짧고 굵은 가로막대 (PRIMARY, 4~5px × 40px)
- **제목 2단**: 국문 대제목(굵게, PRIMARY) + 영문 서브(자간 0.15em, MUTED)
- **카드**: 흰 배경 + LINE 테두리 + 라운드 8~12px. 표보다 카드를 선호한다
- **번호 배지**: CARD 배경 라운드 사각형 + PRIMARY 숫자
- **표지**: 상단 40% **사선 크롭 이미지** — JL 시그니처. 하단 중앙 로고
- **AI 여백 금지**: 콘텐츠로 화면을 채운다. 가운데 텍스트 몇 줄에 사방 여백만 남는 구성을 만들지 않는다.
- **인용 처리**: 공고문·공문 인용은 **원문 그대로** + 형광 하이라이트(`#FFF3A3`). 요약하거나 다듬지 않는다.
- **모식도 표기**: 실측이 아닌 개념도에는 "모식도" 캡션을 단다.
- **추정치 표기**: 계산식 병기. 미확인 항목은 `[미확인]`.

## 2. 레이아웃 방향 3안 — 선택 필요

같은 26장 내용을 세 가지 방식으로 담을 수 있다. **하나를 고르시면 그 방향으로 캔버스를 제작**합니다.

### A안 — 정공법 (검토보고서 승계)

기존 JL 분양공고문 검토보고서의 형식을 그대로 이어받는 안.

- 상단 NAVY 제목 바(높이 96px) + 흰 본문 영역
- 제목은 좌측 정렬 결론 문장형 ("담보책임기간이 2027년 3월 도과합니다")
- 본문은 2단 또는 표 중심. 정보 밀도 높음
- 사진은 본문 안에 정사각/4:3 썸네일로 배치
- 이미지 의존도 **낮음** — 자료가 부족해도 완성됨

적합: 발표 시간이 짧고 심사위원이 내용을 빠르게 훑어야 할 때. 자료가 아직 다 안 모였을 때.
위험: 시각적으로 무난해서 경쟁 제안서 사이에서 눈에 덜 띈다.

### B안 — 다큐멘터리 (사진 전면)

하자 현장 사진을 전면에 세우는 안.

- 표지·PART 간지는 **풀블리드 사진** + NAVY 반투명 오버레이 + 흰 텍스트
- 본문은 흰 배경으로 전환해 가독성 확보
- PART 1(왜 지금인가) 구간에서 하자 사진을 크게 씀 — 좌 사진 / 우 설명 분할
- 이미지 의존도 **높음** — D3(하자사진) 30장 이상, D5(단지 전경) 고해상 필수

적합: 입주민 정서에 호소해야 할 때. 하자가 시각적으로 명확할 때. 총회 발표용.
위험: 사진 품질이 낮으면 역효과. 카톡 압축본으로는 성립하지 않음.

### C안 — 데이터 리포트 (숫자 중심)

수치와 도표로 밀고 나가는 안.

- 카드형 그리드. 숫자 타일(KPI) + 차트 + 표
- 여백을 절제하고 정보를 조밀하게 배치
- 사진은 작은 근거 자료로만 등장
- 인포그래픽 비중 최대 — 그래픽 5종이 각각 1장씩 온전히 차지
- 이미지 의존도 **중간** — 대신 D6(하자 접수대장) 수치 데이터가 반드시 필요

적합: A4 인쇄 책자로 배포할 때. 심사위원이 정량 근거를 중시할 때.
위험: 데이터가 부실하면 빈 껍데기가 된다.

### 권장

**A안을 기본으로 하되 PART 1 구간만 B안 방식으로 처리하는 혼합**을 권합니다. 전체 신뢰감은 정공법으로 가져가고, 승부처인 "왜 지금인가"에서만 사진을 크게 써서 밀도를 올리는 방식입니다. 자료 확보 상황에 관계없이 성립하고, 사진이 많이 들어오면 B 비중을 늘리면 됩니다.

## 3. 슬라이드별 레이아웃 타입 · 그래픽 사양

**`01_제안서_구성안.md`로 일원화했다.** 31장 각각의 고정/가변 구분, 참조 데이터 키, 그래픽 6종 배치가 거기 있다. 두 문서에 나눠 적으면 어긋난다.

이 문서는 **어떻게 그릴지**만 정의한다.

### 가변 슬라이드 렌더링 규칙

| 슬라이드 | 데이터 없을 때 |
|---|---|
| S1 표지 | 단지 전경 → 없으면 **추상 그래픽판**으로 자동 전환 |
| S4 현황 | 항목별 행 삭제 (표 자체는 유지) |
| S5 타임라인 | `사용검사일` 없으면 **생성 불가** — 제작 중단하고 자료 요청 |
| S6 집계 / S7 이력 / S8 사양대조 | 해당 장 **삭제**. 페이지 번호 자동 재계산 |

### 그래픽 제작 도구

`04_이미지_운용규칙.md` 3항 참조. 요약하면 — **레이아웃은 Claude Design, 도해·차트는 인라인 SVG 직접 작성.** 3D 생성은 이 제안서에 쓰지 않는다 (치수 정확도 문제 + 신뢰 훼손 위험).

## 5. 제작 순서

1. 마스터 슬라이드(헤더·브랜드바·타이포) 확정
2. 그래픽 ①(타임라인) 단독 제작 → 이것부터 검토받는다
3. PART 1 (S4~S7) 제작 → 방향 확정
4. 나머지 전개
5. 16:9 캔버스 완성 → 필요 시 A4 재조판 → PPTX/PDF 산출
