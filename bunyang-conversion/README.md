# 파주 운정 휴아림 — 분양전환 법률자문 & 단체등기 제안 (HTML 모션 버전)

원본: `0. 파주 휴아림 약식 단체등기제안서.pptx` (구글드라이브)

## 파일
- `index.html` — 발표용 덱 (브라우저로 열기)
- `assets/PretendardVariable.woff2` — 내장 폰트 (오프라인에서도 동일 렌더링)
- `assets/photos/` — 원본 PPT의 사진·스캔 이미지를 넣는 위치 (미작업)

## 발표자 단축키
| 키 | 기능 |
|---|---|
| `→` `Space` | 다음 단계 / 다음 장 |
| `←` | 이전 단계 / 이전 장 |
| `Enter` | 현재 장의 모든 단계 한 번에 펼치기 |
| `L` | 레이저 포인터 (한 번 더 누르면 크게) |
| `S` | 스포트라이트 |
| `D` / `X` | 펜 필기 / 지우기 (`1` `2` `3` 색상) |
| `B` | 블랙아웃 |
| `T` / `R` | 경과 타이머 / 초기화 |
| `G` | 지난 단계 흐리게 (집중 모드) 켜고 끄기 |
| `O` / `F` / `P` / `H` | 목차 / 전체화면 / 인쇄(PDF) / 도움말 |

무선 프리젠터는 대부분 `PageUp`/`PageDown` 을 보내므로 별도 설정 없이 동작합니다.
