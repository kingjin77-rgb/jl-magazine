## 2. 레이아웃 문법 — 전 페이지 공통

지명원은 모든 면이 같은 골격을 쓴다. 제안서도 이 문법을 그대로 따른다.

```
┌────────────────────────────────────────────────┐
│ ◆ 법무법인 제이엘 · 지명원          08 / 19    │ ← 상단 러너
│                                                │
│ ▬▬  주요 실적                                  │ ← 가로막대 + 국문 대제목
│      TRACK RECORD                              │ ← 영문 서브 (자간 넓게, MUTED)
│                                                │
│  ┌──────┐ ┌──────┐ ┌──────┐                  │ ← 배지 3분할 (CARD 배경)
│  └──────┘ └──────┘ └──────┘                  │
│                                                │
│ 주요 업무 분야  CORE PRACTICE                  │ ← 국문 소제목 + 영문 라벨
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │ ← PRIMARY 굵은 가로선
│  ┌─┬────────────────────────────────────┐    │
│  │1│ 항목명                              │    │ ← 번호배지 + 라운드 카드
│  │ │ 부제 (PRIMARY, 작게)                │    │
│  │ │ 설명 문장                           │    │
│  └─┴────────────────────────────────────┘    │
└────────────────────────────────────────────────┘
```

### 구성 요소

| 요소 | 사양 |
|---|---|
| **상단 러너** | 좌: `◆ 법무법인 제이엘 · 하자소송 제안서` (MUTED, 작게) / 우: `08 / 31` (DARK) |
| **제목 마크** | 제목 왼쪽에 짧고 굵은 가로막대 (PRIMARY, 두께 4~5px, 길이 40px 내외) |
| **대제목** | 국문, 굵게, PRIMARY |
| **영문 서브** | 대제목 아래. 자간 넓게(0.15em), MUTED, 작게 |
| **섹션 헤더** | 국문 소제목(굵게, INK) + 영문 라벨(작게, MUTED) → 아래 PRIMARY 가로선 |
| **카드** | 흰 배경 + LINE 테두리 + 라운드 8~12px. 카드 안은 불릿 리스트 |
| **번호 배지** | CARD 배경 사각형(라운드) 안에 PRIMARY 숫자 |
| **배경 워터마크** | 거대한 JL 로고 또는 영문 제목, WATERMARK 색으로 아주 연하게 |

### 표지 문법

- **상단 40%를 사선으로 자른 이미지.** 사선 절단이 JL 시그니처다
- 이미지 아래 여백 → 국문 대제목(매우 굵게, PRIMARY) → 영문 서브(자간 넓게)
- 그 아래 2줄 정도의 짧은 문장
- **하단 중앙에 로고** (`법무법인 JL / JL LAWFIRM`)
- 배경 흰색, 여백 넉넉

## 3. 톤 — 지명원에서 관찰된 것

- **여백을 넉넉히 쓴다.** 꽉 채우지 않는다
- 국문(굵게) + 영문(자간 넓게, 연하게) **2단 표기**가 모든 제목에 붙는다
- 카드로 정보를 묶는다. 표보다 카드를 선호
- 색을 절제한다. 블루 한 계열 + 회색
- 문장은 담백하다. "…를 완벽히 수호합니다" 정도의 절제된 단정

> **주의**: 하자소송 제안서 톤 규칙(`01_제안서_구성안.md`)은 "승소 보장 금지"다. 지명원의 "완벽히 수호합니다" 같은 표현은 **회사 소개서에는 가능하지만 수임 제안서에는 쓰지 않는다.**
